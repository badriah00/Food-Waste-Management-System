# 🍽️ Food Waste Management System

A web-based Food Waste Management System developed as a graduation project to reduce food waste by connecting food donors with charitable organizations through an easy-to-use online platform.

## 📌 Project Overview

The system allows donors to publish surplus food, enables charities to request available donations, and provides administrators with tools to manage users, monitor donations, and generate reports.

## ✨ Features

- User Registration & Login
- Secure Authentication
- Donor Dashboard
- Charity Dashboard
- Administrator Dashboard
- Food Donation Management
- Donation Request Management
- Reports & Statistics
- User Profile Management
- Responsive User Interface

## 🛠️ Technologies Used

- PHP
- MySQL
- HTML5
- CSS3
- JavaScript
- XAMPP
- phpMyAdmin
- Visual Studio Code

## 🗄️ Database

The system uses a relational MySQL database including the following tables:

- Donors
- Charities
- Administrators
- Food Donations
- Donation Requests
- Reports

## 🎯 Project Objectives

- Reduce food waste.
- Facilitate communication between donors and charities.
- Improve food donation management.
- Provide administrators with monitoring and reporting tools.
